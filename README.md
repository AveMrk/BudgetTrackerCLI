# Budget Tracker CLI

Консольное приложение для управления личными финансами на TypeScript. Позволяет создавать бюджетные счета, учитывать доходы и расходы, просматривать историю транзакций и экспортировать данные в CSV.

## Возможности

- Просмотр списка счетов и их финансовых сводок.
- Создание счетов с уникальными идентификаторами.
- Просмотр транзакций выбранного счета.
- Добавление доходов и расходов с проверкой введённых данных.
- Удаление транзакций с подтверждением.
- Удаление счетов с подтверждением.
- Экспорт транзакций счета в CSV-файл.
- Интерактивное управление через библиотеку Inquirer.

## Требования

- Node.js — версия, совместимая с зависимостями проекта.
- npm.

## Установка

Клонируйте репозиторий и перейдите в каталог проекта:

```bash
git clone https://github.com/AveMrk/BudgetTrackerCLI.git
cd BudgetTrackerCLI
```

Установите зависимости:

```bash
npm install
```

## Запуск

Запустите приложение из корневого каталога проекта:

```bash
npx tsx src/index.ts
```

Следуйте подсказкам интерактивного меню.

## Проверка типов

Если в проекте настроен скрипт `build`, выполните:

```bash
npm run build
```

Если такого скрипта нет, проверьте типы непосредственно через TypeScript:

```bash
npx tsc --noEmit
```

## Структура проекта

- `src/classes/` — классы приложения, счетов, менеджера счетов и транзакций.
- `src/interfaces/` — интерфейсы и пользовательские типы.
- `src/lib/` — вспомогательная библиотека и декларации типов.
- `src/utils/` — вспомогательные функции.
- `src/decorators/` — декораторы TypeScript.
- `src/index.ts` — точка входа приложения.

## Экспорт данных

Экспортированные транзакции сохраняются в CSV-файл. Файл можно открыть в табличном редакторе, например Microsoft Excel или Google Sheets.
